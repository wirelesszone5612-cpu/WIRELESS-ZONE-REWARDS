Wireless Zone Rewards

Upload these 4 files to the ROOT of the GitHub repository:
- index.html
- styles.css
- config.js
- app.js

Do not upload the ZIP itself if you are using GitHub's "Upload files" screen.

Supabase is already configured in config.js with the project's publishable browser key.
No secret/service_role key is included.

After uploading, enable GitHub Pages:
Repository > Settings > Pages
Source: Deploy from a branch
Branch: main
Folder: / (root)
Save

Then open the GitHub Pages URL shown by GitHub.
